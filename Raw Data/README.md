# Raw Data

This folder contains the raw data collected during floral visitor surveys at Arthur's Seat, Edinburgh.

The data files are named "Pollinators" for consistency with the original field data and analysis workflow. However, it should be noted that the study measured **floral visitation rather than pollination**. A recorded visit therefore represents an observed floral visitor visiting a flower and does not indicate that successful pollen transfer or pollination occurred.

The raw data have been retained in their original structure to support transparency and reproducibility.
